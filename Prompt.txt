PHASE 3 — Compute BDS on calibration and verify on holdout
============================================================

Create script:
bss_experiments/unilumos_bds_certificate_v1/scripts/compute_bds.py

For each split:

Compute BDS_low:
- Tset = {10}
- calibration average gain
- bootstrap 95% lower confidence bound
- bootstrap 95% CI
- win rate on calibration
- Hoeffding LCB with gains clipped to [-1, 1]

Compute BDS_all:
- Tset = {10,16,20,24} or available exact same-compute points
- calibration average gain
- bootstrap 95% lower confidence bound
- bootstrap 95% CI
- win rate on calibration
- Hoeffding LCB

Then evaluate holdout:
- holdout mean gain for low
- holdout win rate for low
- holdout mean gain for all
- holdout win rate for all
- whether calibration verdict is confirmed

Bootstrap:
- use 10,000 resamples if cheap, else 2,000
- resample cases, not individual NFE rows, to preserve case-level dependence

Hoeffding:
- clip each case-level averaged gain to [-1, 1]
- delta = 0.05
- LCB = mean - 2 * sqrt(log(1/delta)/(2*n))
where n = number of calibration cases.

Decision rule:
- Green if BDS_all bootstrap_LCB > 0
- Low-only if BDS_low bootstrap_LCB > 0 and BDS_all_LCB <= 0
- Reject if BDS_low_LCB <= 0
- Need-more-calibration if calibration cases < 5 or intervals too wide
