PHASE 1 — Define certification quantities
============================================================

Implement:

`bss_experiments/unilumos_policy_certificate_v1/scripts/certification_utils.py`

Definitions:

For each case \(c\), NFE \(T\), and metric `rgb_l1_closure`:

Same-compute paired gain:
`g_T(c) = Q_BSS_T(c) - Q_uniform_T(c)`

where:
- `Q` = rgb_l1_closure
- uniform and BSS must have same actual NFE T
- reference = reference_uniform25
- low baseline = uniform8

Also compute gains for temporal closure if available.

For each NFE T:
- mean gain
- SEM
- bootstrap 95% CI
- one-sided sign-test p-value for H0: win probability <= 0.5
- win count / total
- Clopper-Pearson lower bound for win probability
- Hoeffding lower confidence bound for expected gain

For Hoeffding:
Compute raw empirical summaries and clipped gain certificate with gains clipped to [-1, 1].
Use delta:
- 0.10
- 0.05
- 0.01

PHASE 3 — Deployment policy selection
============================================================

We want PC-SMO/official evaluation to choose a deployment policy, not just evaluate BSS blindly.

Candidate deployment policies:

1. `never_bss`
   - use uniform at every tested NFE

2. `bss_all`
   - use BSS at every tested NFE where BSS exists

3. `bss_low_only`
   - use BSS at the lowest valid same-compute point only
   - likely T=10

4. `bss_low_mid`
   - use BSS at T <= 16, uniform above

5. `bss_until_positive_calibration`
   - on calibration set, use BSS at NFE T only if calibration mean gain at T > 0; otherwise use uniform

6. `oracle_per_nfe_calibration`
   - choose BSS or uniform per NFE based on which has higher calibration mean closure

For each policy \(\pi\), define per-case score:
`score(c, pi) = mean over tested compute points of rgb_l1_closure(c, method chosen by pi at that NFE)`

Tested compute points should include:
- T=10
- T=16 if available
- T=20 if available
- T=24 if available

Do not include target 20% fallback in aggregate score unless explicitly configured.
Use actual tested NFE points.

For each policy:
- compute calibration score
- holdout score
- full score
- rank

Finite-policy uniform convergence:
Let M = number of candidate policies.
If scores are clipped to [0,1]:
`epsilon = sqrt(log(2*M/delta)/(2*n_calib))`

Regret bound:
`F(pi_star) - F(pi_hat) <= 2*epsilon`

Expected useful outcome:

- This would support the claim:
  “UniLumos should use BSS only in low-compute regime; high-NFE BSS should be rejected.”
